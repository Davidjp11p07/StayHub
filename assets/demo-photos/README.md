# Imágenes proporcionadas para demostración local

Estas diez imágenes fueron proporcionadas por el usuario el 19 de noviembre de 2026 para reutilizarlas en los datos de demostración de StayHub. Los nombres conservan el identificador temporal de las capturas originales. Algunas contienen marcas visibles; no se ha verificado la autoría ni la licencia original. La instrucción del usuario autoriza su uso en esta demostración local, pero no acredita permisos de publicación o redistribución adicionales.

Son imágenes ilustrativas: no se debe afirmar que representan los alojamientos sintéticos ni sus ubicaciones. El seed local `node scripts/seed-demo-properties.mjs` las reutiliza para los inmuebles ficticios. Conserva `.artifacts/demo-properties-state.json`, ignorado por Git, para reanudar sin duplicados; contiene credenciales sintéticas locales y no debe compartirse. Si una creación queda incierta el script se detiene y requiere reconciliar el registro antes de reintentar.
